# 🍕 Pereiras Pizzas — Landing Page & Cardápio Digital

Uma landing page moderna, elegante e focada em alta conversão para a **Pereiras Pizzas (Lago Jacarey / Eusébio)**. O objetivo principal da aplicação é apresentar os produtos com alto apelo visual (*appetite appeal*), fornecer prova social e direcionar os clientes para realização de pedidos via **InstaDelivery** e **WhatsApp**.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 & CSS3** / **Tailwind CSS** (Estilização responsiva e suporte a Dark Mode)
- **JavaScript (ES6+)** (Interatividade e manipulação de abas de cardápio)
- **Design System / Componentes:** Interface focada em dispositivos móveis (*Mobile-First*)

---

## ✨ Funcionalidades

- **📱 Design Mobile-First:** Otimizado para navegação rápida e fluida em smartphones.
- **🍕 Cardápio Interativo:** Separação por categorias (Pizzas Salgadas, Doces, Pizzas Fritas e Bebidas).
- **🛒 Botão Fixo de Pedido (Mobile):** Barra de CTA no rodapé da tela para fácil conversão.
- **⭐ Prova Social:** Exibição de avaliações reais retiradas do Google Maps (Nota 4.6).
- **📍 Informações da Loja:** Endereço, mapa de rotas, horários de funcionamento e contatos diretos.
- **💬 Integração com WhatsApp e InstaDelivery:** Links diretos para atendimento e checkout.

---

## 🎨 Identidade Visual

- **Modo:** Dark Mode (#0d0d0e / Slate-950)
- **Cores de Destaque:** Amarelo/Dourado (`#F59E0B`) para ações primárias e detalhes quentes para apetite visual.
- **Estilo:** Artesanal, aconchegante e moderno.
